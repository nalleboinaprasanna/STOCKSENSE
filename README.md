# StockSense — AI-Powered Stock Market Prediction System

> **Decision-support tool · Not financial advice**

StockSense forecasts next-day stock price direction (UP / DOWN) by fusing three independent signal streams through a two-stage machine learning pipeline, then explains every prediction with SHAP.

---

## Architecture

```
Historical Price Data  →  LSTM Network (60-day window, 16-dim embed)  ─┐
Technical Indicators   →  Feature Vector (13 indicators)               ├→ Feature Fusion (31-dim)
Financial News         →  FinBERT + VADER Sentiment (2 scores)        ─┘
                                                                          │
                                                              XGBoost Classifier
                                                                          │
                                                         SHAP Explanations + Streamlit Dashboard
```

## Quick Start

### 1. Install dependencies

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
# Edit .env and add your NewsAPI key (free at https://newsapi.org)
```

### 3. Train the models

```bash
# Default: AAPL, 5 years of history (~3–8 min on CPU)
python -m modeling.train_pipeline --ticker AAPL --years 5
```

This generates:
- `models/lstm_v1.h5` — trained LSTM embedder
- `models/xgb_v1.json` — trained XGBoost classifier
- `models/training_metrics.json` — accuracy / classification report
- `data/processed/AAPL_features.parquet` — fused feature dataset

### 4. Launch the dashboard

```bash
streamlit run dashboard/app.py
```

Open http://localhost:8501

### 5. Host the dashboard publicly

The Streamlit dashboard can be deployed for free with [Streamlit Community
Cloud](https://share.streamlit.io/). Push this repository to GitHub, then create
an app with:

- **Repository:** `nalleboinaprasanna/STOCKSENSE`
- **Branch:** `main`
- **Main file path:** `dashboard/app.py`
- **Python version:** `3.12` (the pinned dependencies and saved XGBoost models
  are compatible with it)

The supported ticker models are included under `models/` so predictions work
after deployment. Cached OHLCV snapshots for the supported tickers are also
included and used when Yahoo Finance is unavailable from the hosting
environment; the cache refreshes when needed and possible. A NewsAPI key is
optional; to enable live news headlines, add this in the app's Streamlit Cloud
**Secrets** settings:

```toml
NEWS_API_KEY = "your-newsapi-key"
```

Do not commit `.env` or API keys. Streamlit Community Cloud provides the public
app URL after deployment.

## Feature Schema (31 dimensions)

| Stream | Features |
|---|---|
| LSTM Embedding | `lstm_embed_0` … `lstm_embed_15` (16 dims) |
| Technical Indicators | `rsi_14`, `sma_20`, `sma_50`, `ema_12`, `ema_26`, `ema_20`, `macd`, `macd_signal`, `bb_upper`, `bb_lower`, `volatility_10d`, `volume_change`, `daily_return` |
| Sentiment | `finbert_sentiment`, `vader_sentiment` |

---

## Model Details

### LSTM Embedder
- **Input**: 60-day sliding window × F features (normalised with MinMaxScaler)
- **Architecture**: `LSTM(128) → Dropout(0.2) → LSTM(64) → Dense(32) → Dense(16, relu)`
- **Training**: 80/20 split, Adam lr=1e-3, EarlyStopping (patience=5)
- **Output**: 16-dimensional embedding vector per day

### XGBoost Classifier
- **Input**: 31-dimensional fused feature vector
- **Hyperparameters**: n_estimators=300, max_depth=5, lr=0.05, subsample=0.8
- **Split**: chronological 80/20 (no shuffle — prevents data leakage)
- **Target accuracy**: ~74% on held-out test set

### Sentiment Analysis
- **FinBERT** (`ProsusAI/finbert`): transformer-based, maps labels to +1/0/−1 × confidence
- **VADER**: lexicon-based, compound score in [−1, +1]
- FinBERT processes headlines in batches, and repeated sentiment results are cached by the dashboard for one hour. The first FinBERT use may still take longer while its ~440 MB model is downloaded and loaded.

## Error Handling

| Failure | Behaviour |
|---|---|
| yfinance request fails or times out | Falls back to the last cached CSV; requests time out after 5 seconds |
| No headlines | Sentiment defaults to 0.0; headline_count=0 flagged in SHAP panel |
| Feature schema mismatch | Fusion raises `ValueError` — pipeline fails loudly |
| Model artefact missing | Dashboard shows clear missing-model notice; charts still render |
